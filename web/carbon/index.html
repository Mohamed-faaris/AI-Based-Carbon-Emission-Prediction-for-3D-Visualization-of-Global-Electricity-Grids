Data interpretation

CEA baseline values and derived estimates are not interchangeable. CO₂ baseline figures are attributed to the CEA CO₂ Baseline Database. Run-rate values and SO₂/NOx/PM values are estimates with assumptions documented in the source data. Missing values mean unavailable or unmatched data, not zero emissions.

Historical trends use only observed annual intensity points. The projected values are a transparent linear trend baseline and must not be presented as measured emissions.
